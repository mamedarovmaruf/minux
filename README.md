# minux

**minux** is a personal educational project aimed at developing a monolithic hobby operating system kernel from scratch. The primary goal of this project is to explore low-level software development, OS architecture, and hardware interaction.

 **Note:** This is a strictly personal, experimental, and educational project. It is actively updated as a learning sandbox and is not intended for production use.

## Goals & Objectives
* Study x86/x86_64 architecture and boot sequence.
* Implement a basic kernel from scratch (written in C and Assembly).
* Understand memory management, interrupts, and process scheduling.
